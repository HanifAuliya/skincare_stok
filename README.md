# Botanika Lab — Stock Management

A single-page inventory dashboard for a skincare product line: product catalog, stock movements, barcode lookup, and pricing — all in one HTML file.

**Live demo:** https://hanifauliya.github.io/skincare_stok/

## Features

- **Dashboard** with stock status per product (safe / low / out of stock)
- **Products** — add, edit, and delete products with SKU, filter by category, and search by name or SKU
- **Stock in** — record incoming stock with a note (e.g. supplier batch) and view the stock log
- **Barcode scan** — look up a product by SKU and adjust its stock directly from the scan result
- **Pricing table** with Rupiah formatting
- **Settings** page

> This is a front-end prototype: data lives in the page's memory and resets on reload.

## Tech

HTML, CSS, vanilla JavaScript — no build step. Open `index.html` in a browser to run it.
